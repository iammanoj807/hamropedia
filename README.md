# Hamropedia

**[hamropedia.com](https://hamropedia.com)** · News, study-abroad guides and free courses, explained simply.

Hamropedia (हाम्रो, "our", + encyclopedia) is a free website with clear, sourced articles,
four free courses and a few useful tools. Every article shows when it was published and last
updated, and links to the official or named sources it is based on.

## Free courses

Four free courses, with no sign-up and no paywall. New here? Start with the map on
**[Learn & Build](https://hamropedia.com/learn/)**: what each course is for, how every lesson
works, and an order to take them in from zero.

| Course | What you learn | Size |
|---|---|---|
| **[AI & Machine Learning Roadmap](https://hamropedia.com/ai-roadmap/)** | From your first NumPy array to building and shipping LLM apps | 8 phases, 98 lessons |
| **[System Design](https://hamropedia.com/system-design/)** | High-level design, low-level design (OOP, SOLID, design patterns) and AI/ML system design, ending with full interview questions | 10 phases, 72 lessons |
| **[SQL](https://hamropedia.com/sql/)** | From your first `SELECT` to window functions and classic interview problems, with a query runner in your browser | 9 phases, 61 lessons |
| **[DSA (NeetCode 150)](https://hamropedia.com/dsa/)** | The patterns behind coding interviews, one at a time, with the 150 NeetCode problems | 18 patterns, 150 problems |

Every lesson follows the same steps: **understand it** (an animation, the idea step by step, a
diagram, an analogy and a worked example), **go further** (optional free videos and articles),
**practise** (exercises with answers hidden until you try) and **prove it** (four checks you tick
only when you can do them without notes). Underlined words show what they mean when you tap them.

### SQL

[hamropedia.com/sql](https://hamropedia.com/sql/): every lesson uses one small
**[practice database](https://hamropedia.com/sql/practice-database/)** of six tables, with the

### Your progress, without an account

There is no login. Ticks, saved SQL queries and DSA review dates are kept in your own browser.
**Download my progress** (on the [Learn page](https://hamropedia.com/learn/#your-progress) and
each course page) saves them to a small file, and **Load a progress file** puts them back, on the
same device or another one. Nothing is sent anywhere: see the
[privacy policy](https://hamropedia.com/privacy-policy/#courses).

## How the site is built

A hand-built static site (Node.js, no framework) hosted on GitHub Pages:

```bash
npm install
npm run dev      # build into dist/ and serve it at http://localhost:4321
npm test         # unit tests
npm run verify   # checks every page: links, titles, descriptions, canonicals
```

### Updating the courses

The lessons are written in atomic-hub (my own study app) and copied here as JSON:

```bash
npm run sync-courses   # needs atomic-hub next to this repo, or ATOMIC_HUB=/path/to/atomic-hub
npm run build && npm run verify
```

Commit the changed files in `src/data/courses/`. The build only reads those files, never atomic-hub.
`slugs.json` keeps every lesson's URL fixed, even if a topic is renamed in atomic-hub.

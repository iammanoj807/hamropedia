Few skills pay off for a student like programming. Employers in Nepal and abroad want it, every course and tool you need is free, and any laptop is enough to practise on. This roadmap shows **how to learn coding** from zero up to your first real projects, one step at a time and in the right order.

## Step 1: Pick one language (and stick with it)

Your best first language is simply the one you'll keep using. Either of these is a safe bet:

- **Python**, if data, AI, automation or science interest you. Its code reads almost like English. ([python.org tutorial](https://docs.python.org/3/tutorial/))
- **JavaScript**, if you want to build websites and web apps you can show people. ([MDN: JavaScript basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Adding_interactivity))

You might pick up **Java** or **C#** later (large companies, Android, Unity games) or **Go** (cloud and back-end services), but never start three languages at once. Variables, loops, functions and data structures work the same way everywhere, so what you learn carries over.

## Step 2: Set up your tools

- **Editor:** [Visual Studio Code](https://code.visualstudio.com/) costs nothing, runs on Windows, macOS and Linux, and handles every popular language through extensions. (Old tutorials may mention Atom, which was discontinued in 2022.)
- **Language:** install [Python](https://www.python.org/downloads/), or [Node.js](https://nodejs.org/) to run JavaScript outside the browser.
- **Terminal:** learn a handful of commands (`cd`, `ls` or `dir`, running a file). MIT's free [Missing Semester](https://missing.csail.mit.edu/) is the best short introduction.

Don't have a laptop yet? You can begin in the browser with free tools such as [Google Colab](https://colab.research.google.com/) for Python, or [freeCodeCamp](https://www.freecodecamp.org/).

## Step 3: Learn the basics properly

All languages share the same core: **variables and types, conditions (`if`), loops, functions, lists and dictionaries/objects, reading and writing files, and handling errors**.

Good free places to learn them:

- **[freeCodeCamp](https://www.freecodecamp.org/)**: interactive web development and Python courses, with certificates.
- **[CS50 by Harvard](https://cs50.harvard.edu/x/)**: the best-known introduction to computer science, free online.
- **[The Odin Project](https://www.theodinproject.com/)**: a complete web development path at no cost.
- Books: *Python Crash Course* (Eric Matthes) and *[Eloquent JavaScript](https://eloquentjavascript.net/)* (Marijn Haverbeke, free to read online).

Choose **one** course and see it through. Jumping between courses is how most beginners get stuck.

## Step 4: Build projects early

Tutorials train you to follow along; projects train you to think. Keep them small at first, and make each one a little harder than the one before:

1. A tip or GPA calculator.
2. A to-do list that saves to a file.
3. A Nepali-English vocabulary quiz.
4. A personal portfolio website.
5. A small app that uses a public API (weather, currency rates, news headlines).

You will get stuck. When it happens, read the error message slowly, search for it, and look on [Stack Overflow](https://stackoverflow.com/) and in the official documentation.

## Step 5: Data structures and algorithms (DSA)

When the basics feel comfortable, move on to **arrays, linked lists, stacks, queues, hash maps, trees, graphs, sorting, searching and recursion**. They make your programs faster, and they are what most technical interviews ask about.

Practise on [LeetCode](https://leetcode.com/), [HackerRank](https://www.hackerrank.com/) or [Codeforces](https://codeforces.com/). Begin with the "easy" problems and aim to understand the patterns rather than memorise solutions.

## Step 6: Git and GitHub

**Git** records every change to your code, and **GitHub** keeps it online, where it doubles as your public portfolio. Learn to `commit`, `push`, make branches and open pull requests; [Learn Git Branching](https://learngitbranching.js.org/) teaches this visually and is fun. Put each project on GitHub with a short README that says what it does.

## Step 7: Choose a direction

After a few months of basics and projects, choose an area to specialise in:

| Field | You build | Learn next |
|---|---|---|
| Web development | Websites and web apps | HTML, CSS, JavaScript, React, a back-end (Node.js or Python) |
| Mobile apps | Android/iOS apps | Kotlin, Swift, or Flutter |
| Data & AI | Analysis, ML models, AI apps | Python, NumPy, pandas, then the [AI & ML roadmap](/ai-roadmap/) |
| Back-end & cloud | APIs, databases, servers | SQL, a framework, Docker, a cloud platform |
| Cybersecurity | Securing systems | Networking, Linux, security fundamentals |

## Step 8: Learning to code in the age of AI

AI coding assistants can produce a lot of code, which makes understanding code **more** valuable, not less: someone still has to decide whether that code is correct, secure and easy to maintain. Treat the assistant as a patient tutor, not a ghost-writer:

- **Do:** ask it to explain an error, walk through some code line by line, or quiz you on a concept.
- **Do:** write your own solution first, then ask it for a review.
- **Don't:** paste in an assignment and hand in whatever comes back. You'll pass the exercise and fail the interview.

## Step 9: Ship something and join a community

- **Deploy** your projects so other people can use them. [GitHub Pages](https://pages.github.com/) hosts websites for free, and this site runs on it.
- **Find your people:** your college coding club, local meetups and hackathons, and open-source projects on GitHub.
- **Write about your progress** on LinkedIn or a blog. Explaining what you learned is the surest way to remember it.

## Frequently asked questions

**How should a beginner start coding?** Choose one language (Python is the easiest), install VS Code and write a little code every day. Build a tiny project within your first two weeks; it will teach you more than hours of videos.

**What is the best programming language for beginners?** For most people, Python, because its code reads almost like English. If websites are your main goal, start with HTML, CSS and JavaScript instead.

**Can I learn coding for free?** Yes. Every course, tool and practice site in this roadmap is free.

**Is 3 months enough to learn coding?** It's enough for the basics and a few small projects if you put in an hour or two a day. Becoming job-ready takes longer, because you also need DSA, Git and bigger projects.

**Is C++ harder than Python?** For a beginner, yes. C++ leaves more details for you to manage. It's worth learning later, particularly for competitive programming, but Python lets you concentrate on solving problems first.

**What jobs can coding get you?** Web and app development, data analysis, machine learning and AI, testing and DevOps, among others. Step 7 lists the main directions and what to learn for each.

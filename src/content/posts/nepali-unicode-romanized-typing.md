Only have an English keyboard but want to write <span lang="ne">नमस्ते</span>? You don't need a Nepali keyboard or a new layout to learn. **Nepali Unicode Romanized** typing (also called romanized Nepali Unicode) lets you spell words the way they sound in English letters, and they come out as proper Nepali Unicode. This guide covers the typing rules first, then how to type in Nepali on a phone, a laptop, MS Word and Google Docs.

To try it right now, open the free [English to Nepali typing tool](/tools/english-to-nepali/) and type `mero naam`. You'll see <span lang="ne">मेरो नाम</span>.

## Nepali Unicode Romanized typing rules

A handful of rules covers almost everything.

### 1. Long vowels: double the letter (or use a capital)

| Type | Get | Example |
|---|---|---|
| `a` | अ / (no sign) | `kam` → <span lang="ne">कम</span> |
| `aa` or `A` | आ / ा | `kaam` → <span lang="ne">काम</span> |
| `i` | इ / ि | `din` → <span lang="ne">दिन</span> |
| `ee` or `I` | ई / ी | `tIn` → <span lang="ne">तीन</span> |
| `u` | उ / ु | `phul` → <span lang="ne">फुल</span> |
| `oo` or `U` | ऊ / ू | `phUl` → <span lang="ne">फूल</span> |
| `e`, `ai`, `o`, `au` | ए ऐ ओ औ | `mero` → <span lang="ne">मेरो</span> |

### 2. Capital letters for the "hard" sounds

Lower-case `t d n` give <span lang="ne">त द न</span>; capital `T D N` give <span lang="ne">ट ड ण</span>. Likewise `sh` is <span lang="ne">श</span> and `Sh` is <span lang="ne">ष</span>. So `TikaT` → <span lang="ne">टिकट</span>, and `bhaaShaa` → <span lang="ne">भाषा</span>.

### 3. Consonants join on their own

Put two consonants next to each other and they form a conjunct: `namaste` → <span lang="ne">नमस्ते</span>, `prashna` → <span lang="ne">प्रश्न</span>, `shree` → <span lang="ne">श्री</span>. A consonant at the end of a word keeps its normal sound, so `naam` gives <span lang="ne">नाम</span>. Add a backslash when you want a halanta at the end: `garchhan\` → <span lang="ne">गर्छन्</span>.

### 4. Special signs

| Type | Get |
|---|---|
| `M` | ं (anusvara): `saMgIt` → <span lang="ne">संगीत</span> |
| `*` or `~` | ँ (chandrabindu): `sa*ga` → <span lang="ne">सँग</span> |
| `R` | ऋ / ृ: `kRShNa` → <span lang="ne">कृष्ण</span> |
| `ksh`, `tr`, `gy` | <span lang="ne">क्ष, त्र, ज्ञ</span> |
| `.` | । (purna biram) |
| `{English}` | keeps English words as typed |

The [typing tool](/tools/english-to-nepali/) has the full cheat sheet, and its **smart spelling** option fixes everyday words typed casually, such as `nepal` → <span lang="ne">नेपाल</span> and `dhanyabad` → <span lang="ne">धन्यवाद</span>.

## How to type in Nepali on your phone (Android and iPhone)

**Android (Gboard):** in Gboard settings, go to **Languages** → **Add keyboard**, search for **Nepali**, and pick the option that lets you type with English letters (transliteration). The globe key switches between keyboards.

**iPhone:** go to **Settings → General → Keyboard → Keyboards → Add New Keyboard → Nepali**. Apple's Nepali keyboard uses a Devanagari layout, where you tap Nepali letters directly. To type with English letters instead, use a third-party keyboard with transliteration, or type in the [online tool](/tools/english-to-nepali/) and copy the result.

## How to type in Nepali on a laptop or computer

**Quickest, nothing to install:** type in the [online typing tool](/tools/english-to-nepali/), then copy and paste into any app.

**Windows 11 (add a Nepali keyboard):**

1. Open **Start → Settings → Time & language → Language & region**.
2. Choose **Add a language**, search for **Nepali** and install it.
3. Switch between English and Nepali with **Windows key + Spacebar**, or the language icon on the taskbar ([Microsoft Support](https://support.microsoft.com/en-us/windows/manage-the-input-and-display-language-settings-in-windows-12a10cb4-8626-9b77-0ccb-5013e0c7c7a2)).

The Nepali keyboard built into Windows has a Devanagari layout, with a Nepali letter on each key, not Romanized typing. To type with English letters every day, install the [Nepali Unicode Romanized keyboard](#nepali-unicode-romanized-download-for-windows) (below) or keep using the [online tool](/tools/english-to-nepali/). If you learned on the Preeti layout, the [Nepali keyboard tool](/tools/nepali-keyboard/) keeps the same keys and gives you Unicode.

**Mac:** go to **System Settings → Keyboard → Text Input → Edit**, click **+** to add a Nepali input source, and switch with the input menu in the menu bar.

## Nepali Unicode Romanized download for Windows

The **Nepali Unicode Romanized** keyboard comes from **Language Technology Kendra (LTK)**, a joint project of Madan Puraskar Pustakalaya, Tribhuvan University and Kathmandu University. Get it from LTK's official page, [ltk.org.np/downloads.php](https://ltk.org.np/downloads.php), not from download sites that repackage it.

1. On LTK's downloads page, click **Nepali Unicode Romanized** to get `nepali_romanised.zip`.
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and run **setup.exe**. The ZIP contains both 64-bit and 32-bit installers.
4. Switch between English and Nepali with **Windows key + Spacebar**, or the language icon on the taskbar ([Microsoft Support](https://support.microsoft.com/en-us/windows/manage-the-input-and-display-language-settings-in-windows-12a10cb4-8626-9b77-0ccb-5013e0c7c7a2)). LTK's own notes mention **Alt + Shift**.

Worth knowing before you install:

- The installer dates from **2011** and was built with Microsoft's Keyboard Layout Creator. LTK's install notes were written for Windows XP, and the page doesn't say whether it supports Windows 10 or 11.
- **Mac:** the same LTK page has **Nepali Romanized for Mac**. Its instructions say to copy the files into **Library/Keyboard Layouts**, log out, then add the layout under your Mac's keyboard **Input Sources**.
- **No install:** the [online typing tool](/tools/english-to-nepali/) works on the same Romanized idea in any browser.

## How to type in Nepali in MS Word

Word simply types whatever your keyboard sends, so:

1. Add a Nepali keyboard as shown above, or type in the [online tool](/tools/english-to-nepali/) and paste into Word.
2. Choose a **Unicode font** such as **Nirmala UI**, Kalimati or Mangal, never Preeti: text typed in Preeti turns into English letters on any computer without that font.
3. Got an old document in Preeti? Copy its text into the [Preeti to Unicode converter](/tools/preeti-to-unicode/), paste the result back and pick a Unicode font, rather than retyping it.

## How to type in Nepali in Google Docs

Google Docs has Nepali typing built in, with nothing to install:

1. In your document, go to **File → Language** and choose **नेपाली (Nepali)**.
2. An **Input tools** menu appears in the toolbar. Choose the Nepali option that lets you type Nepali words with English letters (phonetic input).
3. Type `namaste` and pick <span lang="ne">नमस्ते</span> from the suggestions. **Ctrl + Alt + Shift + K** (on a Mac, **⌘ + Option + Shift + K**) turns input tools on and off ([Google Docs Help](https://support.google.com/docs/answer/187189)).

## Nepali Unicode Romanized vs Traditional keyboard

The two common Nepali Unicode keyboard layouts both produce the same Unicode text:

- **Romanized (Nepali romanized keyboard):** keys follow the English sound, so `k` gives <span lang="ne">क</span> and `m` gives <span lang="ne">म</span>. It's the easiest if you already type in English, and it's what the rules above and our [typing tool](/tools/english-to-nepali/) use.
- **Traditional:** the old typewriter-style layout, with a fixed Nepali letter on each key that doesn't match its English sound. Fast for people trained on it, slow to learn from scratch. The Nepali keyboard built into Windows is a Devanagari layout of this kind.

Learned on Preeti? The [Nepali keyboard tool](/tools/nepali-keyboard/) uses the Nepali Unicode Traditional layout, which keeps most Preeti key positions and gives you Unicode.

## Use a Unicode font

Type in a **Unicode** font such as **Nirmala UI** (already on Windows 10 and 11), **Kalimati** or **Mangal**, not Preeti, which breaks on any device without the font. The [Preeti to Unicode converter](/tools/preeti-to-unicode/) changes old Preeti text into Unicode, and our [Nepali font download](/nepali-font-download-preeti-kalimati/) guide lists safe downloads of Kalimati, Preeti, Kokila and other fonts.

**How do I type in Nepali on my laptop?** The quickest way is the free [online typing tool](/tools/english-to-nepali/): type with English letters and copy the result. To type Nepali directly in every app, add a Nepali keyboard in your Windows or Mac settings.

**How can I type Nepali in MS Word?** Add a Nepali keyboard to Windows, or paste from the online tool, and set a Unicode font such as Nirmala UI or Kalimati rather than Preeti.

**What is Nepali Unicode Romanized?** A way of typing Nepali Unicode with English letters by sound, so `mero naam` becomes <span lang="ne">मेरो नाम</span>. The rules are at the top of this guide.

**Unicode or Preeti: which should I use?** Unicode. It works everywhere and Google can search it, while Preeti only works where the font is installed.

Looking for a **Nepali font download**? First decide which kind you need. **Unicode** Nepali fonts such as **Kalimati**, **Mangal**, **Kokila** and **Nirmala UI** work on every phone, website and online form. Old fonts such as **Preeti** and **Fontasy Himali** are not Unicode: the text only looks Nepali on a computer that has the font installed. This guide shows where to get each one safely: **Preeti font download** and **Kalimati font download** from official pages, and **Kokila** and **Mangal** straight from Windows. It also shows how to install a Nepali font on Windows and Mac.

## Unicode vs Preeti: which Nepali font do you need?

A **Unicode Nepali font** stores real Nepali letters. Text typed in Kalimati or Nirmala UI stays Nepali when you send it, paste it into Facebook or Gmail, or type it into an online form. Google can search it too.

**Preeti** works differently. It draws Nepali letters on top of English letters, so the file really contains English letters. On a computer without Preeti, your Nepali turns into random English letters. Microsoft explains the general rule: a font you install yourself "will work only with the computer you've installed it on" ([Microsoft Support](https://support.microsoft.com/en-us/office/download-and-install-custom-fonts-to-use-with-office-0ee09e74-edc1-480c-81c2-5cf9537c70ce)). That is why Preeti documents break when you email them to someone who doesn't have the font.

So:

- **New work, online forms, email, social media:** a Unicode font. For a form that asks for your name in Nepali, type it in the [Nepali typing tool](/tools/english-to-nepali/) and paste the Unicode text.
- **An old file typed in Preeti:** install Preeti to read it, or convert it to Unicode once with the [Preeti to Unicode converter](/tools/preeti-to-unicode/).

## Kalimati font download

**Kalimati** is a Unicode Nepali font. It was "developed by Sanir Karmacharya and available for free download from the Nepali Unicode Program" at Madan Puraskar Pustakalaya, according to the University of Chicago's South Asia Language Resource Center ([SALRC](https://salrc.uchicago.edu/resources/fonts/available/hindi/kalimati.shtml)).

Two official pages offer the Kalimati font download:

1. **Lumbini Province Education Training Centre** (<span lang="ne">शिक्षा तालिम केन्द्र</span>, Ministry of Social Development, Lumbini Province): open its [Kalimati font page](https://etc.lumbini.gov.np/downloads/3) and download `Kalimati.ttf`.
2. **UN OHCHR Nepal**: the [downloads page](https://nepal.ohchr.org/en/Downloads.html) lists "Kalimati Unicode Font". It is an old page (marked ©2007), but the file still downloads.

Kalimati is **not** included in Windows. It isn't on Microsoft's Windows 11 font list, not even in the optional Devanagari pack ([Microsoft Learn](https://learn.microsoft.com/en-us/typography/fonts/windows_11_font_list)). So you have to install it yourself. Neither download page states a licence, so use it for your own documents and don't sell it or upload it elsewhere.

## Preeti font download

The **UN OHCHR Nepal** [downloads page](https://nepal.ohchr.org/en/Downloads.html) lists **"Preeti Font"** (the file is `PREETI.TTF`). That is safer than a random download site. A font is a `.ttf` or `.otf` file: if a "font download" asks you to run an `.exe` program, close it.

The page doesn't state a licence for Preeti. Hamropedia doesn't host the font itself.

Before you download, ask whether you really need Preeti:

- **To read or edit an old Preeti file:** yes, install it.
- **To type something new:** use Unicode instead. You can still type with Preeti key positions. The [Nepali keyboard tool](/tools/nepali-keyboard/) uses the Nepali Unicode Traditional layout, which keeps most Preeti keys (the "Preeti font layout"), and gives you Unicode text.
- **To turn Preeti text into Unicode:** paste it into the [Preeti to Unicode converter](/tools/preeti-to-unicode/). It also converts Unicode back to Preeti if an office asks for Preeti.

## Fontasy Himali font download

**Fontasy Himali** is another old non-Unicode Nepali font. The same [UN OHCHR Nepal downloads page](https://nepal.ohchr.org/en/Downloads.html) lists it as **"Fontasi Himali Font"**, and the file is `HIMALLI.TTF`. Like Preeti, it only shows Nepali on computers that have it installed, so use it only to open old files.

## Kokila font download: it's already in Windows

You don't need a download site for **Kokila** or **Mangal**. They are Microsoft fonts, and Windows can add them for free. Microsoft lists **Devanagari Supplemental Fonts** as "Aparajita, Kokila, Mangal, Sanskrit Text, Utsaah" ([Microsoft Learn](https://learn.microsoft.com/en-us/windows/deployment/windows-missing-fonts)).

To add them on Windows 11:

1. Right-click the **Start** button, choose **Run**, type `ms-settings:optionalfeatures` and select **OK**. Or go to **Settings → System → Optional features**.
2. Select **View features** next to **Add an optional feature**.
3. Search for **Devanagari Supplemental Fonts** and tick the box.
4. Select **Next**, then **Add**.

Your PC needs to be online, because Windows downloads the fonts through Windows Update. On some versions of Windows the page is under **Settings → Apps → Optional features** instead ([Microsoft Learn](https://learn.microsoft.com/en-us/windows/deployment/windows-missing-fonts)).

## Unicode Nepali font: free options

- **Nirmala UI**: already on your PC. It ships with Windows 11 and Windows 10 and covers Devanagari ([Microsoft Learn](https://learn.microsoft.com/en-us/typography/font-list/nirmala-ui)). If you type Nepali in Word on Windows, it is the easiest choice: nothing to install.
- **Noto Sans Devanagari**: free from [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari) under the SIL Open Font License, so you can also use it on websites and in designs.
- **Kalimati**: free, but you install it yourself (see above).
- **Mangal** and **Kokila**: free with Windows (see above).
- **Madan** and **Janaki**: Language Technology Kendra's "Nepali Unicode Fonts" download on [ltk.org.np](https://ltk.org.np/downloads.php).

All of these produce the same Unicode text, so you can switch between them at any time. Pick the one that looks best to you.

## How to install a Nepali font on Windows and Mac

The steps are the same for Kalimati, Preeti or any other `.ttf` file.

**Windows:**

1. Find the font file in your **Downloads** folder. If it is a `.zip`, open it first.
2. Double-click the `.ttf` file. It opens in the font previewer.
3. Select **Install** at the top ([Microsoft Support](https://support.microsoft.com/en-us/office/download-and-install-custom-fonts-to-use-with-office-0ee09e74-edc1-480c-81c2-5cf9537c70ce)).
4. Close and reopen Word. The font now appears in the font list.

**Mac:**

1. Double-click the font file in Finder.
2. Click **Install** in the window that appears. Font Book checks the font for errors as it installs ([Apple Support](https://support.apple.com/guide/font-book/install-and-validate-fonts-fntbk1000/mac)).

macOS supports TrueType (`.ttf`) and OpenType (`.otf`) fonts, so Preeti and Kalimati both install the same way.

**Phone:** Android and iPhone show Unicode Nepali without installing a font. To type, add a Nepali keyboard or use the [Nepali typing tool](/tools/english-to-nepali/). See [how to type in Nepali](/how-to-type-in-nepali-unicode-romanized/) for phone and laptop setup.

## Frequently asked questions

**What is the best Nepali font?** For most people, a Unicode font: Nirmala UI is already on Windows, Kalimati is popular for documents, and Noto Sans Devanagari is free for websites. Unicode fonts work everywhere. Preeti only works on computers that have it installed, so use it only for old files.

**How do I install a Nepali font?** On Windows, double-click the .ttf file and select Install. On a Mac, double-click it and click Install in Font Book. Then restart Word or the program you use. The steps are the same for Kalimati, Preeti and other Nepali fonts.

**How do I install Preeti font?** Download PREETI.TTF from a trusted page such as the UN OHCHR Nepal downloads page, double-click it and select Install. Remember that Preeti text only shows correctly on computers with Preeti installed. For new work, type in Unicode or convert with a Preeti to Unicode converter.

**Which Nepali font should I use in MS Word?** Use a Unicode font such as Nirmala UI (already on Windows 10 and 11), Kalimati or Mangal. Choose it from Word's font list after you start typing in Nepali. Avoid Preeti for new documents: it breaks on computers that don't have the font.

**Can I use Preeti font on Mac?** Yes. macOS supports .ttf fonts, so double-click PREETI.TTF and click Install in Font Book. The same limit applies as on Windows: anyone you send the file to also needs Preeti. Converting the text to Unicode avoids that problem.

**Is Kalimati a Unicode font?** Yes. Kalimati is a Unicode Devanagari font, so text typed in it stays Nepali on any device, even one without Kalimati, which usually shows it in another Nepali font. That is the main difference from Preeti.

**Do I need to download a Nepali font for Windows 10?** No. Windows 10 and 11 already include Nirmala UI, which shows and types Nepali. You can also add Kokila and Mangal free through Devanagari Supplemental Fonts in Settings. Only Kalimati, Preeti and other third-party fonts need a separate download.

**Why does my Nepali text turn into English letters?** The text was typed in Preeti or another non-Unicode font, and the computer showing it doesn't have that font. Install the font to read it, or paste the text into a Preeti to Unicode converter to change it into Unicode that works everywhere.
